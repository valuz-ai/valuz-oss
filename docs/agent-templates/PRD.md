## 背景与目标

现在「预设 team」（通用 / 投研 / 产研）这套有价值的资产**只活在 onboarding,用一次就没了**。用户进产品后做新项目,想要一套「投研班底」「内容二创班底」,只能在智能体库里一个个手建 agent——`onboarding.py` 里配好的成套角色,产品里再也取不到。

有用户反馈:onboarding 能选 team,但进产品后**想再加一套 team 没有任何入口**。

**目标**:在**智能体库**(agent 的总入口/池子)里提供一个**官方模板浏览 + 一键添加进个人库**的能力。模板 = 一套配好的角色,一键添加 = 成套打包复制进你的库(各自独立、可编辑)。进库后按现有流程派驻进项目——**派进同一个项目它们就组回成团队**,贴合 Valuz「项目 = 团队」的心智(库是池子,项目才是团队)。

> 明确**不是做「市场」**:市场(分类搜索 / 第三方供给 / 评分 / 安装信任)的前提是有供给生态,现在只有官方几套,套市场的壳是 over-engineering。先做轻的「模板库」,等模板多了、有第三方贡献诉求了再演进成市场。

## 用户故事

- 作为**要做新项目的用户**,我想从模板库一键把一套专业班底(如投研团队)添加进我的库,再派驻进项目,而不必一个个手建角色。
- 作为**想做内容二创的用户**,我能在模板库里直接找到「视频二创团队」,一键添加,马上有一套配好的角色可用。
- 作为**任何用户**,我在智能体库——找 agent 的总入口——就能看到所有可用模板,不用回 onboarding。

## 范围界定

### 包含

- **智能体库内的模板入口 + 模板面板**:库顶部「+」旁加「浏览模板」入口 → 打开模板面板(按场景分组,team 卡显示成员头像)。
- **一键添加进个人库**:批量 `createAgent`(source=custom),**固定 slug 幂等去重**——模板每个角色一个稳定 slug,已在库的跳过;整套都已在库则卡片标「已添加」禁用。
- **模板数据源(后端)**:把现有 i18n 驱动的 team roster **泛化成「模板」结构**(在 name/description/instructions 之上补 **固定 slug + avatar + skills + connector_types + effort**),让角色能 createAgent 成一个像样的 agent。**onboarding 与模板库共享这一份模板定义**。
- **两个 endpoint**:`GET /v1/agent-templates`(列模板)、`POST /v1/agent-templates/{id}:add`(添加模板到个人库,返回新建/已存在的角色)。
- **模型 / effort**:模板角色进库时跟随用户**全局默认**(复用 `_resolve_deploy_target` + `get_default_effort`,和 onboarding 一致)。
- **首批模板**:两套**完整定义**的旗舰 team——**投研 Team**(skill 与 MCP 从 claude-for-financial-services-cn 原样移植)和**小红书内容创作 Team**(平台 team,装备最轻、最快落地);外加一套**世界杯预测 Team**(2026 限时,双 runtime 平行情报 + GPT-5.5 海报,是「runtime / 模型中立」卖点的 showcase 与传播素材);通用 / 产研沿用 onboarding 现有定义迁移。**全部角色的完整定义(slug/runtime/instructions/skills/connectors/effort)见 [teams.md](teams.md)**。

### 不包含

- **不做「市场」**:分类搜索、第三方供给、评分、安装信任、权限——后续演进。
- **不做一键直接派进项目**:模板只添加进个人库;派驻进项目用现有流程。库与项目解耦。
- **不接视频二创团队的 MCP 工具**:视频下载/字幕转录、封面出图、平台数据回流——第一版靠角色指令引导用户,工具接入留二期。
- 不动 onboarding 现有「选 team → 部署进示例项目」的用户体验(只是底层模板定义统一)。

## 模板与角色定义(数据结构)

```
AgentTemplate {
  id: str               # 模板唯一 id, 如 "investment" / "video-repurpose"
  scenario: str         # 分组场景, 如 "投研" / "内容创作"
  name: str             # "投研 Team"
  description: str      # 一句话定位
  icon: str             # 头像/图标 key
  roles: Role[]         # 成套角色
}

Role {
  slug: str             # 固定唯一 slug(去重靠它), 如 "industry-analyst"
  name: str
  description: str
  instructions: str
  avatar: str           # 头像 key
  skills: str[]         # 挂载的 skill slug
  connector_types: str[]
  effort: EffortLevel | null
}
```

- 现有 3 套(general/investment/product)从 `onboarding.roles.<team>.<role>.*` 的 i18n 定义**迁移/扩展**:补 slug、avatar、skills。文案继续走 i18n(按 locale baked)。
- onboarding 的部署逻辑改为读这份共享模板定义(行为不变,仍部署进示例项目)。

### 内容创作类模板 — 按平台拆 team(设计原则)

> 内容场景**不做大而泛的"内容 team"**:平台/形态一变,skill 和 mcp 几乎全变,
> 硬塞一个 team 会角色爆炸。**按平台拆**,每个 team 内部装备一致、角色精简、流程到「发布」闭环为止
> (数据复盘是发布后、依赖后置数据的独立动作,不进创作 team)。

首批上**小红书内容创作 Team**(4 角色:选题策划 → 种草写手 → 配图设计 → 发布运营,
全 team 仅 1 个 MCP,完整定义见 [teams.md](teams.md));
**抖音/视频号短视频 Team**(口播脚本、文生视频,MCP 较重)作为后续平台 team 排期。

### 投研 Team — 基于金融 skill 包(首批旗舰)

4 角色:行业分析师 → 财务建模师 → 业绩跟踪员 → 研报撰写人,skill 移植自
claude-for-financial-services-cn 并**改写为全球股票市场口径(美股/港股/A 股为主)、去掉 `china-` 前缀**,
数据用 Valuz 自有 MCP(`valuz-search` 检索 + `valuz-data` 行情,OAuth 登录即用)。完整定义见 [teams.md](teams.md)。

## 界面与交互

### 页面:智能体库(AgentsPage)+ 模板入口

```
┌─ 智能体 ─────────────────────── [浏览模板] [+] ┐  ← 新建:「浏览模板」入口
│ 〔自定义〕                                       │
│  🤖 我的 Agent A          ···                    │  ← 现有列表(复用)
│  ...                                            │
│ 〔官方〕                                          │
│  ...                                            │
└─────────────────────────────────────────────────┘
```

### 页面:模板面板(点「浏览模板」打开)

```
┌─ 从模板添加 ─────────────────────────────────┐
│ 选一套配好的角色,一键添加进你的库            │
│                                               │
│ 投研                                          │  ← 按场景分组
│ ┌─────────────────────┐                      │
│ │ 💎 投研 Team          │  ◍◍◍◍ 4 角色        │
│ │ 行业+估值+跟踪+合规    │  [添加到我的库]      │
│ └─────────────────────┘                      │
│ 内容创作                                       │
│ ┌─────────────────────┐                      │
│ │ 🎬 视频二创团队        │  ◍◍◍◍◍◍◍ 7 角色    │
│ │ 把混乱二创变成生产线   │  [添加到我的库]      │
│ └─────────────────────┘                      │
│ ┌─────────────────────┐                      │
│ │ 🧩 通用 Team          │  ✓ 已添加(禁用)      │  ← 整套已在库则禁用
│ └─────────────────────┘                      │
└───────────────────────────────────────────────┘
```

- **新建**:智能体库的「浏览模板」入口 + 模板面板(Dialog/抽屉),按场景分组,模板卡显示 name/description/成员数。
- **复用**:成员头像渲染(`AVATAR_PRESETS`)、`createAgent` 进库逻辑。
- **交互**:点「添加到我的库」→ 后端对每个角色 createAgent(固定 slug,已存在跳过)→ toast「已添加 N 个 Agent」→ 库列表刷新 → 整套已在库的模板卡转「已添加」禁用。

### 关键流程

1. **浏览**:智能体库 →「浏览模板」→ 模板面板。
2. **添加**:选模板 →「添加到我的库」→ 后端按固定 slug 批量 createAgent(已存在的跳过、只补缺的)→ 进库。
3. **使用**:用户在库里把这些 agent 派驻进项目(现有流程)→ 组成团队。

## 已确认

1. **部分已添加 → 补齐缺失**:用户删过某角色再点添加,只建库里没有的那几个;只有整套都在库时,模板卡才标「已添加」禁用。
2. **第一版只做 team 模板**:不支持单个 agent 模板(如把「Valuz 小助手」放进模板库),留后续。
3. **入口 = 智能体库顶部「浏览模板」按钮**:不做成列表里的分组。
